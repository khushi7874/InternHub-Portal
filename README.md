# InternHub Portal

InternHub is a simple internship portal website built with HTML, Bootstrap, and custom CSS.

## Project Structure

- `home.html` - Landing page with carousel and banner
- `login.html` - User login page
- `register.html` - Registration page for new users
- `contact.html` - Contact page with support details and message form
- `forgot-password.html` - Password reset request page
- `css/style.css` - Shared custom stylesheet
- `logo.svg` - Site logo used in the navbar
- `favicon.svg` - Browser tab icon
- `photo1.avif`, `photo2.avif`, `photo3.avif` - Home page carousel images

## Usage

1. Open any of the `.html` files in a browser.
2. Use the navbar links to navigate between pages.
3. The site uses Bootstrap for layout and styling, with custom CSS in `css/style.css`.

## Notes

- The project is static and does not include backend authentication.
- Forms are styled for appearance only and do not submit to a server.
